# Spanline — Minecraft Utility Mods

Fünf kleine **Forge**-Mods für **Minecraft 1.21.11**. Fertige **`.jar`-Dateien** liegen im Ordner [`jars/`](jars/) — direkt nach `.minecraft/mods/` kopieren.

**Version 1.1.2** — Mixins hängen nicht mehr beim Bootstrap.

**Repository:** https://github.com/lolalpha00gamma/minecraft-utility-mods

| Mod | JAR | Was sie tut |
| --- | --- | --- |
| **Infinite Water** | [`infinite-water-1.1.2.jar`](jars/infinite-water-1.1.2.jar) | Volle Wassereimer bleiben voll. Leere Eimer bleiben leer. |
| **Mining Reach** | [`mining-reach-1.1.2.jar`](jars/mining-reach-1.1.2.jar) | Block-Reichweite +8 (4.5 → 12.5). |
| **Beacon Range** | [`beacon-range-1.1.2.jar`](jars/beacon-range-1.1.2.jar) | Beacon-Radius ×3. |
| **Elytra Speed** | [`elytra-speed-1.1.2.jar`](jars/elytra-speed-1.1.2.jar) | Elytra-Schub ×2, Cap 6 Blöcke/Tick. |
| **Villager Lead** | [`villager-lead-1.1.2.jar`](jars/villager-lead-1.1.2.jar) | Villager an die Leine, auch über Blöcke nach oben. |

## Installieren

1. Alte Spanline-JARs (`1.1.0` und `1.1.1`) aus `mods/` löschen
2. Die `.jar`-Dateien aus [`jars/`](jars/) nach `.minecraft/mods/` kopieren
3. Launcher mit dem Forge-Profil starten
