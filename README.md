# Spanline — Minecraft Utility Mods

Fünf **Forge**-Mods für **Minecraft 1.21.11**. Fertige **`.jar`-Dateien** in [Release 1.1.5](https://github.com/lolalpha00gamma/minecraft-utility-mods/releases/tag/v1.1.5).

**Version 1.1.5** — Hot-Reload Configs, Einstellungen in JSON.

**Repository:** https://github.com/lolalpha00gamma/minecraft-utility-mods  
**Download:** https://github.com/lolalpha00gamma/minecraft-utility-mods/releases/tag/v1.1.5

| Mod | JAR | Was sie tut |
| --- | --- | --- |
| **Infinite Water** | `infinite-water-1.1.5.jar` | Voll bleibt voll, leer bleibt leer. |
| **Mining Reach** | `mining-reach-1.1.5.jar` | Block-Reichweite +8 (4.5 → 12.5). |
| **Beacon Range** | `beacon-range-1.1.5.jar` | Beacon-Radius ×3. |
| **Elytra Speed** | `elytra-speed-1.1.5.jar` | Elytra-Schub ×2, Cap 6 Blöcke/Tick. |
| **Villager Lead** | `villager-lead-1.1.5.jar` | Villager an die Leine, auch über Blöcke. |

## Installieren

1. Alte Spanline-JARs aus `mods/` löschen
2. Die `.jar` aus [Release 1.1.5](https://github.com/lolalpha00gamma/minecraft-utility-mods/releases/tag/v1.1.5) nach `.minecraft/mods/` kopieren
3. Forge 1.21.11 starten
4. Optional: JSON in `config/` — Änderungen greifen nach ~2 Sekunden
